# Thesis Project

This folder contains experimental videos from my thesis on MPC-based vibration control of a flexible robotic arm.

The project includes dynamic modelling of the flexible arm, identification of necessary parameters, strain-gauge-based vibration measurement, payload estimation, and real-time MPC control for position tracking and vibration reduction as well as proxy based reference shaping for compliant behavior and safe interaction.

The thesis report, source code, controller implementation, mathematical models, and additional experimental materials will be added after the thesis is officially published.
